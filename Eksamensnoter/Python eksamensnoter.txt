*** Dunder-methods ***
Kaldes også magic methods (virker som om der sker noget magi i baggunden)

Dunder methods er allerede implementeret i indbyggede typer
Python’s indbyggede typer som list, dict, str, int osv. har allerede dunder methods implementeret.

Dunder methods kan også implementeres i egne klasser og dermed bestemme, hvordan objekter skal opføre sig.

Når jeg bruger +, kalder Python faktisk __add__, og når jeg bruger for, kalder Python __iter__.
Det samme gælder for built-in funktioner som len() og print().

Iterator-protokollen
- hvad er det
- dunder metoderne
- EKSEMPEL		

Når jeg bruger "for", kalder Python __iter__.
Iteration i Python fungerer via iterator-protokollen, som består af __iter__ og __next__.
Når for-loopet starter, kalder Python iter(obj), som igen kalder objektets __iter__-metode.
Derefter kalder Python gentagne gange __next__ for at få næste værdi.
Når __next__ rejser StopIteration, ved Python, at løkken skal stoppe.
På den måde kan vores egen klasse fungere i et for-loop på præcis samme måde som en liste eller en range.
For-loops virker ens for alle objekter, der følger iterator-protokollen.
